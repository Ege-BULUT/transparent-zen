Task Board

Tasks

Backlog → Analyze → Planning → Development → Ready for Review → Testing → Accepted (Done) / Rejected. See the roadmap for the milestone order tasks get created in. Agents mutate this board through scripts/tasks_cli.py, never by hand-editing the JSON.

How this board works
  • The task board's data lives in data/tasks.json. This page renders a read view from it via scripts/tasks_cli.py render. Every mutating command re-renders automatically.
  • Fully local. No server, no fetch, no network call anywhere on this page. The board data is embedded directly in this file at render time.
  • Drafting a comment or logging a session in this UI does not save anywhere by itself (there's nowhere local-only to save it to). It builds the exact CLI command for you to run, which is the one thing that actually persists it.
  • Open questions and working notes belong in agent memory, not in a task comment thread.
  • Cards in Ready for Review, Testing, Accepted, and Rejected are draggable: drop a card on another column to get a one-line update command you can run in your terminal (or copy to clipboard). Other columns stay click-only because moving out of backlog/development is the agent CLI's job. Drag-drop on those would let humans bypass the claim flow.
