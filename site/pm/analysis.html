  How this board works
  
    
    
  • Data lives in data/analysis.json. scripts/analysis_cli.py render regenerates
      this page from it, and every mutating command re-renders automatically.
    • 
    
  • As many categories as the review actually needs: the diagram draws one circle per category and
      the overlap is the point. Past three circles a true Venn is geometrically impossible, so only the
      regions that hold findings are drawn, each disc sitting where its categories meet. A finding that
      fits none of them is a task, so it belongs on the board instead.
    • 
    
  • Mark a fix with analysis_cli.py status F-0001 --set fixed --note "how it was verified". The
      note is the evidence, so write what you actually checked, not that you checked it.
    • 
    
  • Findings are a snapshot of one review. Long-lived work belongs on the roadmap,
      and the reasoning behind a call belongs in agent memory.
