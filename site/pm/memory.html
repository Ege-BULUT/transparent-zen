Agent Memory

Journals

Each journal is a log an agent (or a human) owns and names: working notes, decisions, dead ends, handoffs. Read the relevant one before redoing analysis someone already did. Persisted through scripts/memory_cli.py; this page is the rendered view.

Journals

Write your content to a file first, then run this (it reads --content-file). Re-open this page after, it re-renders automatically.

    

    

  

  






  How this journal works
  
    
    
  • Data lives in data/memory.json. scripts/memory_cli.py render regenerates this
      page from it. Every create/append/update/contributor
      call re-renders automatically.
    • 
    
  • The content pane is editable in-browser for quick edits, but nothing here saves itself; there's no
      server. Use Copy content, save it to a file, then memory_cli.py append (adds a
      timestamped section, the normal case) or update --content-file (replaces the whole body).
    • 
    
  • One journal per distinct thread of work, named by whoever owns it. Don't pile unrelated work into one
      entry just because it already exists.
