Unofficial community edition

Every website, in the theme you choose

Light, Dark and Transparent themes for Zen Browser. One generic engine instead of hand-written styles per website, with a single slider that controls how see-through your pages and the browser interface are.

Get started Follow the board View source
This is not the official Transparent Zen. It is an independent fork maintained by Ege-BULUT. The official project by FrostyBiscuit is available on GitHub and on Mozilla Add-ons. Please report issues with this edition to this fork, not upstream.

Three themes, two kinds of transparency

Pick a theme from the extension popup. The choice applies to every website, and you can still exclude single domains.

Light

Dark websites are turned light. Pages that are already light stay untouched.

Dark

Light websites are turned dark, while photos and videos keep their real colors.

Transparent: Partial

Only backgrounds become see-through. Text, buttons and images stay solid and readable.

Transparent: Full

The whole page fades, including text, images and controls, for a true glass look.

In both transparent modes the slider also reaches the Zen interface: sidebar, toolbar and borders fade together with the page, using the companion stylesheet described below.

Install on Windows 11

The edition is not on Mozilla Add-ons yet. Until the first signed release, load it from source.

  1. Open about:config in Zen and set these to true: browser.tabs.allow_transparent_browser, widget.transparent-windows, widget.windows.mica.
  2. Build the extension: 
    git clone https://github.com/Ege-BULUT/transparent-zen
cd transparent-zen
npm ci
npm run build:extension
  3. Open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on and select manifest.json.
  4. Optional, for the Zen interface: set toolkit.legacyUserProfileCustomizations.stylesheets to true and zen.theme.disable-lightweight to false, copy zen-mod/userChrome.css into the chrome folder of your profile, then restart Zen.
  5. Optional: install MicaForEveryone, add a process rule for zen, enable Blur Behind and set the backdrop type to Acrylic for a stronger blur.
